# 06 — Chat UI (CampusAssist)

## What it is

A **single-page web chat** students and professionals open in a browser.  
It is the **only** user-facing app. No login, no admin, no multi-page portal.

**Name on screen:** CampusAssist  
**Subtitle:** College rules, exams & admission  
**Repo:** `ui/` (Vite + vanilla HTML/CSS/JS)  
**Host:** S3 + CloudFront HTTPS URL  

---

## What topics it covers (via chat + KB)

The UI itself is generic chat; **coverage comes from the knowledge base + tools** behind it:

| Topic | How user reaches it | Backend |
|---|---|---|
| Attendance / exam rules | Type or chip #1 | RAG → regulations / exams docs |
| Medical leave / missed exam | Chip #2 | RAG multi-doc |
| Admission deadlines | Chip #3 | **Tool** `get_admission_deadline` (+ optional RAG) |
| Admission documents | Chip #4 | RAG → admission brochure |
| Fees / support ticket | Chip #5 | **Tool** `create_ticket` |
| Free-form campus FAQ | Type any related question | RAG (+ tools if needed) |
| Off-topic | e.g. “poem about Mars” | Agent refuses; UI just shows the reply |

UI does **not** have separate pages per topic—one chat covers all.

### Sections

1. **Header** — Brand first (CampusAssist), short subtitle  
2. **Prompt chips** — 5 one-click demo questions  
3. **Message list** — Scrollable user/assistant bubbles  
4. **Per-answer extras**
   - **Citations** — doc name + short snippet (RAG trust moment)  
   - **Tool badge** — e.g. “Checked admission deadline” when a tool ran  
5. **Composer** — text input + Send (Enter to send)  
6. **Footer** — Bedrock + AgentCore credit line

## How it works (front → back)

1. Page load → create/read `sessionId` in `sessionStorage`  
2. User clicks chip or types message  
3. UI appends user bubble; shows loading (“Thinking…”)  
4. `POST https://{api}/chat` with body:

```json
{
  "message": "Last date for B.Tech admission this year?",
  "sessionId": "uuid-from-sessionStorage"
}
```

5. Invoke Lambda → AgentCore Runtime → reply  
6. Expected response shape (UI will render):

```json
{
  "reply": "The last date for B.Tech admission is 30 June 2026.",
  "citations": [
    {
      "title": "admission/brochure.md",
      "snippet": "B.Tech applications close on 30 June 2026…"
    }
  ],
  "toolsUsed": ["get_admission_deadline"],
  "sessionId": "same-uuid"
}
```

7. UI appends assistant bubble + citations + tool badges  
8. On error: show red/inline error; keep prior messages  

**No AWS keys in the browser** — only the public API Gateway URL (injected at build/deploy as `VITE_API_URL`).

## Behaviors included

| Behavior | Detail |
|---|---|
| Multi-turn | Same `sessionId` for follow-ups on stage |
| Loading | Disable Send while request in flight |
| Empty send | Ignore blank messages |
| Chip click | Fills/sends that exact golden prompt |
| Citations | Listed under answer when array non-empty |
| Tool badge | One pill per name in `toolsUsed` |
| Full reply | Wait for complete JSON (streaming not required) |
| Mobile | Readable on phone (single column); not a native app |

## Explicitly out of scope

- Login / Cognito / roles  
- Uploading PDFs from the UI  
- Admin / analytics dashboard  
- Voice, file attach, markdown editor  
- Dark-mode toggle, themes store  
- i18n beyond English for the demo  

---

## Look & feel

- Campus **blue/teal + white**  
- Font: Source Sans 3 or IBM Plex Sans (not Inter/Roboto/Arial)  
- One continuous chat composition (not a card dashboard)  
- Chips + composer are the interactive controls  

---

## Golden chips (hardcoded in UI)

1. What is the minimum attendance for semester exams?  
2. Can I get medical leave for a missed mid-sem?  
3. Last date for B.Tech admission this year?  
4. What documents are required for admission?  
5. Raise a support ticket for fee clarification  

These match the live demo script in [05-DEMO-SCRIPT.md](05-DEMO-SCRIPT.md).

## Build & deploy

| Step | Command / action |
|---|---|
| Local | `cd ui && npm install && npm run dev` |
| Build | `npm run build` → `ui/dist` |
| AWS | Actions uploads `dist` → S3; CloudFront serves HTTPS |

---

## Why this UI for the talk

- Students see a real chatbot in seconds  
- Professionals see citations + tool badges = RAG vs Agents made visible  
- One URL on the slide; no app install
