# 05 — Demo script (~15–20 min live)

## Golden prompt chips

1. What is the minimum attendance for semester exams?  
2. Can I get medical leave for a missed mid-sem?  
3. Last date for B.Tech admission this year?  
4. What documents are required for admission?  
5. Raise a support ticket for fee clarification  

## Flow

1. **Hook (1 min)** — Campus FAQ overload → CampusAssist  
2. **RAG (3 min)** — Prompt 1 → show citation  
3. **Multi-doc (3 min)** — Prompt 2  
4. **Agent tool (5 min)** — Prompt 3 (+ optional 5 for ticket)  
5. **Hosting (3 min)** — CloudFront URL + AgentCore Active  
6. **Pro close (2 min)** — KB = truth, tools = actions, AgentCore = host; cost tens of dollars  

## Backup

- 30s screen recording of A1–A3 if Wi‑Fi fails
